# V3 完整封面 Imagegen Prompt 模板

本模板用于填充每个 `aspect_group` 的真实 `prompt.md`。不得把尖括号占位符原样传给图片模型。

## 任务

Use case: `infographic-diagram`

Create one complete Chinese article-cover master for the exact target aspect ratio `<TARGET_WIDTH>:<TARGET_HEIGHT>`. Generate a newly composed cover for this ratio. Do not stretch, mechanically crop, or merely extend a cover made for another ratio.

## 输入图片角色

- `primary-style-authority`：主参考图。它是暖米白纸张、粗糙马克笔标题、不规则边框、箭头、圆圈、涂抹和信息密度的权威。
- `mandatory-identity-reference`：露可丝原始 IP。它是脸、琥珀金眼睛、凌乱深棕短发、金色羽状发饰、墨绿色金边短背心、白色立领宽袖套装、圆形金色叶片徽章和腰侧绿色饰带与金色沙漏挂件的权威。
- `approved-master-cover-reference`（可选）：同一文章已经人工批准的另一比例母图。只继承内容关系和视觉语言，不直接裁切或拉伸。

## 标题事实源

把批准后的标题逐行原样写入：

```text
<TITLE_VERBATIM>
```

- 只出现这一组标题。
- 每个汉字、英文单词、大小写和行序必须完全一致。
- `<EMPHASIS_TEXT>` 使用珊瑚粉粗糙马克笔强调，其余使用炭黑。
- 使用不规则、多笔触、可见纸面摩擦的手绘字；不要使用干净无衬线字、代码排版、描边、投影或 3D 字。
- 标题位于左上或中左，保持一个明确层级，并与边框留出自然内边距。

## 内容事实源

- 核心概念：`<CORE_CONCEPT>`
- 视觉隐喻：`<METAPHOR_DESCRIPTION>`
- 流程顺序：

  1. `<FLOW_1>`
  2. `<FLOW_2>`
  3. `<FLOW_3>`
  4. `<FLOW_4_OPTIONAL>`

流程使用 3～4 个简单手绘圆形图形和明确箭头表达，不画长标签、步骤编号、矩形卡片或第二组标题。图形语义必须按批准顺序出现。

## 露可丝

- `pose_id`：`<POSE_ID>`
- 姿势意图：`<POSE_INTENT>`
- 露可丝位于右侧，约占画面 25%～32%，面向并参与左侧内容。
- 手势必须可观察地完成姿势意图，手部自然、清楚，无额外手指、肢体或融合。
- 保持凌乱深棕短发、金色羽状发饰、琥珀金眼睛、墨绿色金边短背心、白色立领宽袖套装、圆形金色叶片徽章，以及腰侧绿色饰带与金色沙漏挂件。
- 不得为了配色改变头发、发饰、眼睛、服装、徽章、饰带或沙漏挂件的颜色与形态。

## 风格与构图

- 暖米白纤维纸张、炭黑粗糙马克笔线、珊瑚粉主强调、极少量青色辅助。
- 中等信息密度，约 75%～85% 的视觉填充。
- 使用不规则重复线、手绘箭头、圆圈、胶带、涂抹和少量笔记装饰。
- 允许内层封面的单一不规则边框。
- 标题、露可丝完整脸部与关键手势、全部流程图形和核心隐喻尽量位于中央构图区域；这只是生成提示，不能替代生成后平台校验。

## 安全区路由

- 用户没有明确提出裁切、安全区、多种展示比例共用或平台裁切校准时，不添加安全区合同，不为平台名主动缩小整组内容，也不预留大面积纸张带；使用正常设计内边距和上述 75%～85% 视觉填充。
- 用户明确要求安全区时，把已批准的实际裁切范围写入 prompt；内容应尽量填满该安全区域，只保留一层正常内边距。
- 不得为了“更保险”把实际裁切百分比再次放大，也不得同时要求“大安全边距”和“前景只占较小百分比”。安全区与额外缩放只能选择一层，避免裁切后仍有大面积留白。
- 没有真实平台截图时，理论共同裁切范围只能标为构图假设；不能写成平台已经验证。

### `shared-crop-core`

只有 group 声明 `semantic_core` 时使用以下替代合同：

- `<TARGET_WIDTH>:<TARGET_HEIGHT>` 使用 semantic core 的精确比例，不使用最终上传图比例。
- 整张图就是完整语义核心；标题、流程、露可丝和关键装饰在画面内使用正常设计内边距，不画可见安全区、裁切框、外围留白带或第二画布。
- 顶部 12.5% 必须只有与主体一致的暖米白纸张和轻微纸纤维：不得出现标题、人物、头发、发饰、徽章、饰带、图标、箭头、下划线、边框、胶带、强调线、装饰或任何其他墨迹。该条带由代码检查并用于派生上传图外围背景。
- 不画外层边框。内容核心本身保持中等信息密度；不得因为最终上传图更宽而主动缩小 core 内的标题、流程或人物。
- prompt 可以记录理论 crop 的共同交集来源，但不能要求模型在图中表现它，也不能描述为平台实测保证。

## 文字与负面约束

- 除逐字标题外，不出现任何其他汉字、英文、数字、步骤标签、伪文字、签名、Logo 或水印。
- 禁止企业蓝渐变、白黄大标题、PPT 流程框、Dashboard 卡片、重阴影、玻璃拟态、发光粒子、光滑 3D、糖果色、石油绿/橙棕主色、随机几何背景、复杂 AI 大脑/机器人/未来城市场景和大面积空白。

## 定向修正

初次生成后如果存在明确缺陷，只允许再生成一次。修正 prompt 必须写明一个具体缺陷、需要改变的内容和全部必须保持不变的已接受部分。不得用第二次生成顺便重做未被指出的内容。
